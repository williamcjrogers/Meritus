# QCS research provider contracts

Implementation dated 12 September 2026. QCS operates the software and holds the supplied National Archives computational-analysis licence. Its actual agreement, attribution and approved coverage wording belong in the source rights record. No substitute licence application or artificial corporate-holder restriction is introduced here.

The source registry validates the complete job payload, including the fixed window and provider selection. All acquisitions use the shared validated transport, including DNS pinning, authorised hosts, credentials and SQL request reservations. These are implemented interfaces, not a claim that a configured live account has passed acceptance. Offline regression responses are synthetic; `src/lib/research/fixtures/source-manifest.json` intentionally contains no invented capture hashes.

Barbour documents the base `https://api.barbour-abi.com/v4`, projects, companies, `limit`/`offset`, 500 maximum page size, a 10,000-record search ceiling, `project_last_published` partitions and `/projects/merges` plus `/companies/merges`. Developer/Locations entitlements, current applicable contract and an authorised sample are still needed before enabling that API. Imported merge/alias fields are retained as observations; they do not automatically merge entities. The publicly audited client terms applied to contracts entered between 16 October 2024 and 11 May 2026, and do not establish September 2026 purchase terms.

Glenigan's audited terms constrain internal use, derived statistics and third-party distribution. Creditsafe report and monitoring availability depends on the actual contract and current catalogue. No automatic external feed is enabled by importing either dataset.

The local CSV splitting command is `node scripts/research/split-csv.mts --input /absolute/research/export.csv --output /absolute/research/parts`. It writes complete quoted records, repeats the header, limits each part to 16 MiB, refuses overwriting parts and writes raw-input plus part hashes. `previewImportManifest` requires every part and verifies hashes and row counts before labelling the supplied set complete. Hashes prove supplied bytes, not publisher authenticity.

Case-law search reads only available current versions in the requested workspace, supports passage search, exact identifiers, court, party, judge and dates, and preserves publisher passage order. Citation identifiers are not unique keys. The ordinary comparison service selects exact passages. `compareAuthoritiesWithModel` additionally requires an explicit budgeted run; it returns proposed issue/holding/reasoning with exact quotation checks and repeats current-version checks after generation. Reviewed treatment requires explicit supporting passages. Neither service claims exhaustive corpus coverage or commercial citator equivalence.

Source failure, missing parser coverage, missing measures and unconfirmed entity links remain visible. The source unit does not read client-deposited objects. Publication, outreach, purchase, deployment and production migration are separate actions.
